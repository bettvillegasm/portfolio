PORTAFOLIO BETTI — CORRECCIÓN DE IMÁGENES

En esta versión las imágenes están incluidas directamente dentro de index.html.
Esto evita que desaparezcan por rutas incompletas en GitHub Pages o al abrir una vista previa.

PARA ACTUALIZAR:
1. Descomprime el archivo ZIP.
2. Sube el index.html actualizado a la RAÍZ del repositorio.
3. Si NO has subido videos previamente, sube también la carpeta media completa (conservando su nombre).
4. El resto de las carpetas se incluyen como respaldo, por si necesitas usarlas después.

La vista previa HTML independiente puede mostrar imágenes sin las carpetas auxiliares.
La reproducción de MP4 locales sí requiere que la carpeta media esté junto a index.html.
Los elementos externos de Facebook, YouTube o LinkedIn dependen del sitio proveedor.

No cambies los nombres de carpetas ni muevas index.html a una subcarpeta.
